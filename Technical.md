# Gilded Rose Refactoring Kata

Refactored implementation of the Gilded Rose kata using SOLID principles, Strategy Pattern, and xUnit testing.

## Features

- Clean and maintainable architecture
- Strategy-based item handling
- SOLID principles applied
- Extensible item update system
- Comprehensive unit tests

## Supported Items

- Normal Items
- Aged Brie
- Backstage Passes
- Sulfuras
- Conjured Items

## Run Project

```bash
dotnet run --project GildedRose.Console
```
